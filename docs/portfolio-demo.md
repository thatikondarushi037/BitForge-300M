# 2–4 minute portfolio recording

Activate the prepared environment and keep the checkpoint files generated by
the reproduction guide. Start screen recording with your preferred local
recorder (for example Win+Alt+R where supported). These commands are a live
demonstration; no screenshots or results are fabricated.

## 0:00–0:30 — introduction

Open README.md and its Mermaid architecture diagram. Say:
"BitForge investigates ternary weight storage and quantization-aware training.
The full 297M model runs locally, but it is untrained. A separate small model
was trained on synthetic CC0 text. Inference currently uses dense floating-point
kernels, not native ternary acceleration."

## 0:30–1:10 — real full model

```powershell
python -m bitforge model-info --checkpoint artifacts/release-full-final/full.bft | Select-String 'parameters|checkpoint_type|device|checkpoint_bytes'
python -m bitforge benchmark --checkpoint artifacts/release-full-final/full.bft --device cuda --sequence-length 8 --warmup 2 --repeats 5 --generation-tokens 2
```

Point to 297,059,328 parameters, finite `[1,8,32000]` logits, measured allocated
and reserved memory, median latency and throughput. Two generated random bytes
are a smoke test; do not read them as meaningful text.

## 1:10–1:40 — trained offline demo

```powershell
python -m bitforge demo --checkpoint artifacts/release-demo-final/demo.bft --device cuda --prompt "The technician will " --max-new-tokens 32
python -m bitforge generate --checkpoint artifacts/release-demo-final/demo.pt --device cpu --prompt "The technician will " --temperature 0.8 --top-k 40 --top-p 0.9 --seed 42 --max-new-tokens 24
```

State "600 updates on repetitive synthetic data; validation perplexity about
9.95. The repetitions are a real limitation, not a polished language model."

## 1:40–2:20 — storage and numerical verification

```powershell
Get-Item artifacts/release-full-final/full-master.pt,artifacts/release-full-final/full.bft | Select-Object Name,Length
python -m bitforge verify-checkpoint --checkpoint artifacts/release-full-final/full.bft --reference artifacts/release-full-final/full-master.pt --device cuda
Get-Content artifacts/release-summary-final/summary.json
```

Explain the measured full-size ~6.02x compression and byte-packed storage.
Loading reconstructs dense tensors; the packed file does not remain a two-bit
GPU model. Exact CPU reconstruction and small CUDA floating-point differences
are different from BF16 numerical error and from QAT device-reduction changes.
